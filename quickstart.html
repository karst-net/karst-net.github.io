Karst quickstart

Open the Karst administration console and complete First-run setup. You need the public HTTPS URL of your coordination server.

  1. Enter the public server URL in First-run setup.
  2. Create a one-time enrolment key. Copy it immediately; it is shown only once.
  3. Install the Karst node package on the machine you want to connect. Put the one-time key in [control] setup_key in /etc/karst/karstd.toml, alongside the server URL and pins from the installation guide. Validate it with sudo karstd check --config /etc/karst/karstd.toml, then start it with sudo systemctl enable --now karstd. There is no karst up command.
  4. Open Machines and confirm the new node has a current observation and crypto posture.

If the node is absent or stale, check its service logs and confirm its coordination-server URL before generating another key. Never paste a one-time key into a ticket, chat, or shell history you do not control.
